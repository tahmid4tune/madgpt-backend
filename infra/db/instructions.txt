After running the docker image of PG Vector, connect the DB or get into the container using the credentials mentioned in the docker-compose.yml file.
Then open psql tool and run following 2 commands:

madgptDB=# CREATE EXTENSION IF NOT EXISTS vector;
madgptDB=# \dx

==================
